How codes are built

The tariff schedule runs in chapter order, from live animals to special provisions. Open a range and drill it down: chapter, then heading, then subheading. The movement and destination set above decide the answer.

Every range except 99 carries at least one six-digit line in this demo, and only chapters with lines are listed inside a range. Chapter 99 is reserved for country-specific provisions, so it opens a short note instead of a list.

What Is an HS Code in Shipping?

An HS code is the Harmonized System code, an internationally standardized way of classifying traded goods, developed and maintained by the World Customs Organization. Customs authorities use it to identify what is moving, assess the duties that apply, and check the trade requirements that go with the product.

The international code carries six digits. Countries and customs territories can add further digits on top of those six for their own tariff and statistical schedules, which is why the code you file is often longer than the one you search.

An HS code has ten digits. Digits 1 and 2 are the chapter, 3 and 4 the heading, 5 and 6 the subheading, and 7 to 10 the country classification.

How to Determine the HS Code for Your Product

Start with a detailed product description, then verify the classification against the customs tariff that will apply.

Have the code already? Enter two, four or six digits instead.

  1. 1

    Identify the product's key characteristics

    Write down the material, the main function, the composition and any technical specification that changes what the item is. Say whether you are shipping a finished product, a component, or a set.

  2. 2

    Search using a specific description

    Use the lookup at the top of this page to begin. “Men's knitted cotton T-shirt” gives the classifier more to work with than “shirt”, and it usually returns a shorter candidate list.

  3. 3

    Review the classification details

    Compare the headings and subheadings that came back, including the legal notes that govern them. A word in the description matching a tariff line does not by itself confirm the classification.

  4. 4

    Check the destination's requirements

    Confirm whether the destination needs digits beyond the six-digit HS code. If the classification still is not clear, consult a customs broker or seek a customs ruling where the market offers one.

Are HS Codes Different for Each Country?

At the six-digit level the HS is internationally standardized, so the same product shares the same six-digit classification across markets. Countries and customs territories can add digits for more detail, so the full declaration code can differ even when the first six digits match.

Shipping into the United States? Imports are filed on the ten-digit HTSUS line. Open the HTS lookup to see the line and duty rate.

HS Code Lookup FAQs

The questions that come up most often when a code has to travel with a shipment.

How many digits are HS codes?

An international HS code has six digits: the first two identify the chapter, the first four the heading, and all six the subheading. Countries may add digits, so the complete code required for a customs declaration can be longer.

Do I need an HS code to ship internationally?

For most international shipments of goods, an HS-based classification is needed for customs processing. You may need to provide it when preparing a commercial invoice or submitting declaration data. The exact requirement varies by destination, shipment type and carrier.

Is an HS code required on a packing list?

Not universally. Whether the code has to appear on a packing list depends on the destination's documentation rules and on the requirements of the carrier, broker or buyer. Confirm for your own shipment instead of relying on a generic template.

Is an HS code the same as an HTS code?

Not exactly. The HS is the international six-digit system. In the United States, the HTSUS builds on it for import classification and adds digits, so a six-digit HS code may not be enough for a U.S. import declaration.

Does an HS code tell me the import duty rate?

It identifies the tariff classification, but it does not set the final duty on its own. The rate that applies also depends on the destination, the goods' origin, and any preferential treatment or additional trade measure in force.

Does automating HS code classification reduce customs delays?

Automation can cut classification errors and make the data more consistent, which may remove some avoidable delays. Suggested codes still need checking: thin product descriptions, missing documents and ordinary customs inspection can hold a shipment regardless of how the code was selected.
