How codes are built

The tariff schedule runs in chapter order, from live animals to special provisions. Open a range and drill it down: chapter, then heading, then subheading. The direction and destination set above decide the answer.

Chapter 01 carries the full six-digit dataset. Every other range keeps a small sample so the drill-down still works. Chapter 99 is reserved for country-specific provisions, so it opens a short note instead of a list.

How to read an HS code

Every code is built the same way: six digits shared internationally, then the digits the importing country adds on top.

An HS code has ten digits. Digits 1 and 2 are the chapter, 3 and 4 the heading, 5 and 6 the subheading, and 7 to 10 the country classification.

Background

Who publishes the digits?

The six-digit level is maintained as an international schedule, so the same code means the same thing across borders. Each country then publishes its own tariff schedule for the digits that follow, and updates it on its own timetable.

Why do I see multiple results?

Material, construction and intended use can each move a product into a different subheading, so more than one result is normal. The narrowing question removes the options that do not fit your item. Check the product details before you settle on one.

Questions about HS codes

Can I search using a product name?

Yes. Enter a description such as “cotton T-shirt” or “ceramic mug”. The results are candidate classifications, not a single confirmed code, so review the details before choosing.

Can I look up a code I already have?

Yes. Enter a six-digit HS code such as 610910 to see its description and where it sits in the classification structure. Leading zeros are kept, so codes like 090121 work too.

How do I find a destination-specific code?

Choose the destination in the lookup form. Every result shows the six-digit code and the local lines that country applies, in one answer. Changing the country updates both the search results and the chapter answer.

Why are there multiple possible classifications?

Heading and subheading text is written around material, construction, intended use and sometimes the wearer. A cotton T-shirt that is knitted is classified differently from a woven cotton shirt, so the narrowing question asks for exactly that detail.

What should I do if there are no results?

Try a more specific product name, add the material or intended use, or check the digits. You can also open a chapter below and pick the line from there.

Can I use the results directly for customs declarations?

No. This demo runs on a small mock dataset and is not connected to any official tariff database. Use it to understand the structure, then confirm the code with the official tariff schedule or a customs broker before you file.
